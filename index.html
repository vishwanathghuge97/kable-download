Kable

Send files and clipboard between your phone and laptop.

Directly over your own Wi-Fi. No accounts, no cloud, no tracking.

Download for Android

Android 7.0 or newer, on a 64-bit phone. Works with a Linux laptop or another Android phone.

This page installs the Android app; the Linux companion is set up separately. The button always serves the latest version.

Open this page on your phone

Set up Kable

  1. 1
    Install the Android app

    Tap Download for Android above. If your browser asks, allow it to install unknown apps. Turn that off again afterwards.

  2. 2
    Open Kable on both devices

    Choose Add a device in each one.

  3. 3
    Pair the two devices

    Show the pairing code on one device and scan it with the other. Check the code matches, then allow on both.

  4. 4
    Send something

    Send files or clipboard text or images. Both devices must be on the same Wi-Fi.

If something does not work

  • Android blocked the install. Allow your browser to install unknown apps, tap Download for Android again, then turn that permission off afterwards.
  • The other device does not appear. Both devices must be on the same Wi-Fi. Some networks block discovery, for example guest or client-isolated Wi-Fi; a VPN on either device can do the same. Try Refresh in Settings, under Paired devices.
  • A transfer fails. Keep Kable open on both devices, check free space, then use Retry in the transfer list.
  • An update fails. Check your internet connection and free space, then try again. Only install Kable from this page.

Already have Kable? Open Settings, then About, then Check for updates. Kable checks the download before Android installs it. Only install Kable from this page.

Privacy

  • No account, no cloud, no tracking.

  • Your data stays on your devices. Files and clipboard travel directly over your local Wi-Fi.

  • This site has no cookies and no analytics. It is a single static page.
