# kable-download

This repository hosts the public Kable download page at:

https://vishwanathghuge97.github.io/kable-download/

It is a static site (HTML and CSS, no JavaScript) served by GitHub Pages.
Open `index.html` for the page, `icon.png` for the app icon and `qr.svg` for
the QR code that opens the page on a phone.

- The Android APK is attached to the **latest** GitHub Release of this repo.
  The page's download button always points at that release.
- `latest.json` is generated by the release tool during a release. Never
  create or hand-edit it — regenerate it with the release tool instead.
- This repo contains no keys, secrets or credentials. The page has no
  cookies, no analytics and no tracking.

## Preview locally

    python3 -m http.server 8765 --directory .

Then open http://localhost:8765/ .
