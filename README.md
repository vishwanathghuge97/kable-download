# Kable download page

The Apps by Vishwanath marketplace has moved to its own project:

- Local: `/home/vishwanath/Desktop/exp/AppMarketplace`
- Live: <https://vishwanathghuge97.github.io/>
- Repo: <https://github.com/vishwanathghuge97/vishwanathghuge97.github.io>

This branch now only carries Kable's download page source in
`site/kable-download/`. It publishes to
<https://vishwanathghuge97.github.io/kable-download/> through the
`kable-download` repo. The marketplace index links to it as
`/kable-download/`, so the back-links in the page (`../`) still resolve on the
published site.

## Preview locally

```sh
python3 -m http.server 8765 --directory site
```

Open <http://localhost:8765/kable-download/>. The page's back-link to the
marketplace (`../`) only resolves on the live site; that is expected.

## Publishing

Copy the **contents** of `site/kable-download/` into the `kable-download` repo,
keeping `.nojekyll` and `robots.txt`. Commit and push. No build step, no
dependencies, no JavaScript.

`latest.json` is **not** part of this folder and must never be created or
edited by hand. It is generated by Kable's release tool during a release. If it
is missing or wrong, regenerate it with the release tool — do not write one.

## Release-day checklist

1. Confirm the `kable-download` repo's latest GitHub Release carries assets
   named exactly `kable.apk`, `kable-linux-x64.tar.gz` and
   `kable-linux-x64.tar.gz.sha256`. The buttons point at
   <https://github.com/vishwanathghuge97/kable-download/releases/latest/download/kable.apk>
   and <https://github.com/vishwanathghuge97/kable-download/releases/latest/download/kable-linux-x64.tar.gz>.
   Tap each (or open it in a browser) and confirm the download starts.
2. Confirm `latest.json` is the file produced by the release tool during the
   release, not something hand-created or hand-edited.
3. Check the published page: <https://vishwanathghuge97.github.io/kable-download/>
   — page loads; icon and QR render; **Download for Android** starts the APK
   download; **Download for Linux** starts the tarball download; the
   one-command section and setup steps are intact.
4. Confirm <https://vishwanathghuge97.github.io/kable-download/install.sh> is
   this folder's `install.sh`, and that it downloads and checksum-verifies the
   current tarball.
5. Point a phone camera at the QR code on the published page and confirm it
   opens <https://vishwanathghuge97.github.io/kable-download/>.
6. Confirm the repo contains `.nojekyll` (so Pages serves files as-is) and no
   keys or other secrets.

## QR code

`site/kable-download/qr.svg` encodes
`https://vishwanathghuge97.github.io/kable-download/`. It uses a 4-module quiet
zone, black modules on white, and no logo overlay, so any scanner should read
it. It was generated with the `qr` Dart package via a throwaway script; if the
page URL ever changes, regenerate the SVG; do not hand-edit it.
